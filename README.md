# کراولر کاروان صنعت — فاز ۱ (اجرای دستی، فایل‌محور)

این نسخه‌ی پایه همان مراحل ۱ تا ۵ طرح تیم فنی است: هر مرحله یک فایل CSV می‌سازد و مرحله‌ی بعد همان را می‌خواند. همه‌ی فایل‌ها UTF-8 با BOM هستند و در اکسل درست باز می‌شوند. سرور لازم نیست؛ روی یک لپ‌تاپ اجرا می‌شود.

## نصب

```bash
python -m venv .venv && source .venv/bin/activate      # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                                     # کلید API ها را اینجا بگذارید
```

فایل تاکسونومی را با نام `data/taxonomy.csv` بگذارید (نسخه‌ی فعلی داخل بسته هست).

قبل از اولین اجرا در `config.yaml`:
- `fx.manual_rate_toman`: نرخ دلار امروز به تومان، یا `fx.provider: json_api` با آدرس API دلار خودتان.
- `sources.yaml`: سایت‌های منبع هر دسته (پایین‌تر توضیح داده شده).

## اجرا، مرحله به مرحله

```bash
# ۱. صف کراول از تاکسونومی (فقط برگ‌هایی که روی سایت محصول ندارند)
python -m crawler queue --run pilot --path "درایو و اینورتر موتور"

# ۲. جستجو در منابع
python -m crawler search --run pilot

# ۳. کراول صفحه‌ها و استخراج اطلاعات            ← با اینترنت داخل (بدون VPN)
python -m crawler crawl --run pilot

# ۴. فیلتر هوش مصنوعی: محصول به دسته می‌خورد؟     ← با دسترسی به Claude API
python -m crawler filter --run pilot

# ۵. ادغام تکراری‌ها و مقایسه با محصولات فعلی سایت
python -m crawler dedupe --run pilot --site-export path/to/woo-products-export.csv

# ۶. فایل‌های ایمپورت ووکامرس
python -m crawler export --run pilot

python -m crawler stats --run pilot     # آمار هر مرحله
```

هر مرحله را می‌شود وسط کار قطع کرد و دوباره اجرا کرد؛ ردیف‌های تمام‌شده دوباره انجام نمی‌شوند. صفحه‌های دریافت‌شده ۱۴ روز در `data/cache` می‌مانند، پس اجرای دوباره بعد از اصلاح کد به سایت‌ها فشار نمی‌آورد.

گزینه‌های مفید `queue`: `--level1 شیرآلات` · `--path "شیر برقی"` · `--ids 3578 3579` · `--limit 20` · `--mode enrich` (برگ‌هایی که محصول دارند، برای به‌روزرسانی قیمت) · `--mode all`.

## اضافه کردن منبع

در `sources.yaml` برای هر سایت یکی از سه نوع:

- `woo_store_api`: بهترین گزینه. تست: آدرس `https://SITE/wp-json/wc/store/v1/products?search=درایو` را در مرورگر باز کنید؛ اگر JSON دیدید، سایت این را دارد و اطلاعات کامل بدون باز کردن صفحه می‌آید.
- `woo_search`: سایت ووکامرسی بدون API.
- `url_template`: هر سایت دیگری؛ آدرس جستجو و انتخابگر CSS لینک محصول را بدهید.

با `level1` می‌شود هر سایت را فقط برای دسته‌های خودش جستجو کرد. جستجو در کل وب (کشف سایت تازه) با `search.use_web_search: true` و کلید Serper فعال می‌شود؛ ترب، دیجی‌کالا و چند سایت دیگر کنار گذاشته شده‌اند.

مسیر هر دسته (iran / foreign / both) در `config.yaml` → `routes` تعیین می‌شود و به زیرشاخه‌ها به ارث می‌رسد؛ اگر ستونی به نام `Route` به فایل تاکسونومی اضافه کنید، آن ستون اولویت دارد.

## اجرای دستی و اینترنت

مراحل ۲ و ۳ برای سایت‌های ایرانی با اینترنت داخل بهتر جواب می‌دهند. مرحله‌ی ۴ (Claude API) و منابع خارجی معمولاً VPN لازم دارند. اگر VPN یک پراکسی محلی می‌دهد، آن را در `http.proxy.foreign` بگذارید تا لازم نباشد بین مراحل VPN را خاموش و روشن کنید.

## مسیریابی خودکار (صفحه‌ی «مسیریابی»)

برای هر برگ تاکسونومی تصمیم گرفته می‌شود محصول از کجا بیاید: `iran` (فروشگاه‌های ایرانی)، `foreign` (Made-in-China) یا `both`.

1. **قاعده‌های رایگان** (`crawler/routing.py`): برند داخل نام دسته (`brands.csv`) ← ایرانی؛ دسته‌های اصلی بومی (بذر، کود، مصالح ساختمان، …) و واژه‌های قطعه/یدکی ← ایرانی؛ بقیه باز می‌مانند.
2. **سنجش بازار** (`crawler/probe.py`): برای هر گروه (سطح ۳، نه هر برگ) یک جستجوی فارسی Serper. فروشگاه‌های ایرانی قیمت‌دار ≥ `iran_min_priced` ← ایرانی؛ فروشگاه‌ها ≤ `foreign_max_shops` ← Made-in-China؛ بین این دو ← هر دو. فروشگاه‌های پیداشده منبع کراول همان گروه می‌شوند. نتیجه در `data/probes.csv` ذخیره می‌شود و دوباره جستجو نمی‌شود؛ مصرف در `data/serper_usage.csv`.
3. **بررسی ۱۰۰تایی** (`crawler/routing_state.py`، جدول `data/routing.csv`): فقط ردیف‌های غلط علامت می‌خورند و مسیر درست انتخاب می‌شود؛ بقیه درست حساب می‌شوند. هر بررسی یک خط `ROUTING_REVIEW` در لاگ سرور می‌نویسد.
4. **کراول دسته**: ردیف‌های تأییدشده اجرای `batch-N` می‌شوند (همه‌ی مرحله‌ها، با عبارت انگلیسی از `glossary/groups_en.csv` برای Made-in-China).

## بهترین ۲۴ و نام فارسی

- **انتخاب** (`crawler/ranking.py`): برای هر دسته حدود ۴۰ کاندید جستجو و کراول می‌شود و بعد از فیلتر و ادغام، ۲۴ محصول با بیشترین امتیاز کیفیت می‌ماند. امتیاز از ۱۰۰ است: ارتباط ۳۰، قیمت ۲۰، تعداد فروشنده ۱۰، مدل ۱۰، مشخصات ۱۵، عکس ۱۰ و نشان تأمین‌کننده ۵. از هر فروشنده حداکثر ۳ محصول می‌ماند. بقیه در `05_not_selected.csv` قرار می‌گیرند. تنظیم در بخش `select:` فایل config است.
- **نام فارسی** (`crawler/fa_name.py`): برای محصولات انگلیسی، نام از اسم دسته‌ی کاروان، مدل و حداکثر ۳ مشخصه‌ی کلیدی ساخته می‌شود. مشخصات با `glossary/specs_fa.csv` و `values_fa.csv` فارسی می‌شوند. موارد ناشناخته در `data/untranslated.csv` جمع می‌شوند تا به واژه‌نامه اضافه شوند. هیچ مدل زبانی و هزینه‌ای در کار نیست.

## انتشار مستقیم در سایت (`crawler/publish.py`)

کارت «انتشار در سایت کاروان» در صفحه‌ی اجرا، محصولات تازه‌ی یک اجرا را با API ووکامرس به‌صورت **پیش‌نویس** می‌سازد؛ دقیقاً همان چیزی که در `06_woo_import.csv` می‌رود (با تصمیم‌های صفحه‌ی بازبینی، توضیحات و عکس‌ها).

- **SKU ثابت** `CRV-…` از آدرس صفحه‌ی منبع: انتشار دوباره همان محصول را پیدا و به‌روز می‌کند و تکراری نمی‌سازد. وضعیت محصولی که در سایت منتشر شده هیچ‌وقت عوض نمی‌شود.
- **دسته**: شناسه‌ی تاکسونومی (و دسته‌های اضافه‌ی صفحه‌های ادغام‌شده) با `assets/wp_categories.csv` به ID دسته‌ی وردپرس تبدیل می‌شود. محصول بی‌دسته ارسال نمی‌شود. (نسخه‌ای در `DATA_DIR` اولویت دارد.)
- **قیمت دلاری**: قیمت سایت دلاری است و سایت خودش در نرخ روز ضرب می‌کند؛ پس `price_usd` کراولر (با نرخ کراولر؛ چینی‌ها با ضریب) ارسال می‌شود. قیمت تومانی کراول در متای `_caravan_price_toman` می‌ماند.
- **برندها** (`crawler/brands_fa.py`، جدول `data/brands_fa.csv`): هر برند خارجی با DeepSeek یک نام کوتاه و تلفظ فارسی می‌گیرد، «آنتو (Antu)»؛ اسم کارخانه‌ی چینی کوتاه می‌شود و نام اصلی در ستون «نام اصلی» و متای `_caravan_supplier` می‌ماند. برند ایرانی همان‌طور می‌ماند و اسم فروشگاه ایرانی برند حساب نمی‌شود. جدول در کارت انتشار ویرایش می‌شود؛ ردیف دستی دیگر عوض نمی‌شود. برند به بخش «برندها»ی ووکامرس (تطبیق با برندهای موجود، ساخت برند تازه) و به نام محصول اضافه می‌شود: «فلوتر آسانسوری یک اینچ برند آنتو (Antu)» (اگر نام خودش برند را نداشته باشد). محصولی که برندش در جدول نیست ارسال نمی‌شود.
- **نام تمیز** (`crawler/names.py`): «قیمت و خرید …»، «(( اقساط یک ساله ))»، «{ قیمت امروز + مشخصات }»، «- ابزار بیات»، «با چک صیادی …» و ترجمه‌ی انگلیسی تکراری از نام حذف می‌شوند؛ مشخصات (سرعت، دیسکی، …) و «(های کپی)» می‌مانند. محصولی که برند ندارد، اگر نامش برندی از جدول یا brands.csv را دارد، همان برند را می‌گیرد.
- **عکس‌ها** از دیسک سرور با رمز برنامه‌ی وردپرس در کتابخانه‌ی رسانه آپلود می‌شوند؛ هنگام به‌روزرسانی فقط اگر محصول عکس نداشته باشد.
- «فقط بررسی» همه‌چیز را چک می‌کند و چیزی نمی‌فرستد (`07_publish_check.csv`). نتیجه‌ی ارسال‌ها با لینک ویرایش در `07_published.csv`.
- کلیدها روی سرور: `WC_URL`، `WC_KEY`، `WC_SECRET` (دسترسی Read/Write)، `WP_USER`، `WP_APP_PASSWORD`. دکمه‌ی «تست اتصال» همه را بدون نوشتن چک می‌کند.

## رابط وب (Render)

`app.py` همین مراحل را با یک صفحه‌ی فارسی اجرا می‌کند: بارگذاری تاکسونومی و خروجی سایت، ویرایش منابع و تست هر سایت، تنظیم نرخ دلار، اجرای مرحله‌ها با نوار پیشرفت و گزارش زنده، و دیدن و دانلود همه‌ی فایل‌ها.

```bash
APP_PASSWORD=رمز python app.py        # http://localhost:8000
```

روی Render: کلیدها (`APP_PASSWORD`، `ANTHROPIC_API_KEY`، `SERPER_API_KEY`) در بخش Environment سرویس تنظیم می‌شوند. روی پلن رایگان دیسک با هر ری‌استارت پاک می‌شود؛ بعد از هر اجرا فایل‌ها و یک پشتیبان را دانلود کنید. سرور خارج از ایران است و بعضی سایت‌های ایرانی IP خارجی را می‌بندند؛ برای آن‌ها یا پراکسی ایرانی بدهید یا روی کامپیوتر خودتان با خط فرمان اجرا کنید.
